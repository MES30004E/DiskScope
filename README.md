# DiskScope for macOS

DiskScope is a native storage explorer for Apple Silicon Macs running macOS 14 or later. It scans locally and includes a folder hierarchy, rectangular treemap, circular sunburst and a Collector for reviewing files before moving them to Trash.

This repository hosts DiskScope’s download website, public release files and update metadata. The application source code is private.

The website is currently a development preview. Public downloads and their SHA-256 checksums will appear in [GitHub Releases](https://github.com/MES30004E/DiskScope/releases) when a verified release is ready.
