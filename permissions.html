macOS permissions

Start with the folder or volume you want to scan. DiskScope reads filesystem metadata for storage analysis. macOS controls which locations the app can access and may ask you for consent. Open DiskScope → Settings → Privacy & Access to review your options.

Saved folders and individual volumes

Use Scan Folder… to select a specific location. DiskScope keeps saved locations for later use. If it needs a new selection, use Re-authorise… on the saved location and select it again. If a drive or network share is unavailable, reconnect or mount it before retrying. Scan each mounted volume you want to measure.

macOS can ask separately for access to locations such as Desktop, Documents, Downloads, removable drives and network volumes. Review DiskScope’s entries under System Settings → Privacy & Security → Files & Folders. Apple’s guide to file access.

Full Disk Access for broader scans

Full Disk Access is optional. It covers broad filesystem privacy protections, including data from Mail, Messages and Safari and some Time Machine data. Select Open Full Disk Access Settings from DiskScope’s Privacy & Access settings. In macOS, add DiskScope from Applications if needed and turn the switch on. Quit and reopen DiskScope if prompted, then rescan.

If you have multiple copies or replaced the app, check that the copy you run is the one enabled in System Settings. DiskScope reports what it could scan. The Full Disk Access switch in System Settings shows the grant itself. Apple’s Privacy & Security settings guide.

Photos, Music and other apps’ data

Photos library access and Media & Apple Music have their own controls in Privacy & Security. A regular folder of image or music files follows filesystem access rules. DiskScope’s storage scan does not require granting PhotoKit access. If macOS shows a Photos or other-app data request during a scan, you can decline and review the partial result. Apple’s privacy categories.

macOS can separately protect app data containers and app group containers, even inside a folder you selected. Application Support may contain its own restricted app data. Apple’s overview of app container protection.

File permissions, backups and iCloud Drive

File ownership, POSIX mode bits, access control lists and System Integrity Protection still apply. They can restrict access to other users’ folders, backup volumes or protected system data. For an item you own, inspect Sharing & Permissions in Finder’s Get Info. Apple’s overview of filesystem access restrictions.

iCloud Drive can require macOS file access consent. Cloud-only items may also report little or no local disk usage until downloaded. For a file you need to make available locally, use Download Now in Finder. Apple’s iCloud Drive guide.

Partial scans

DiskScope scans items it can access. Use Scan Issues to see which paths could not be read and why. The totals can be incomplete when a location is denied, disconnected or skipped. Rescan after fixing access to a location you want measured.
