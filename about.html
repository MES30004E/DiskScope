About DiskScope.

DiskScope is an independent native macOS storage explorer. It builds on the idea of seeing disk usage as a map, familiar from Disk Inventory X, with a native file hierarchy, rectangular and circular views, and a Collector for preparing a cleanup.

Privacy and access

DiskScope scans locally. File names, paths, sizes and saved inventories stay on the Mac. Storage analysis requires no account or cloud service. Saved scans live in the user’s private Application Support folder and are marked as potentially stale because files can change after a scan.

You choose folders and grant additional access through macOS. For more information, see the macOS permissions guide.

The update channel makes HTTPS requests to retrieve release information and downloads. Those requests omit your file inventory. This website uses no analytics, external fonts, advertising or third-party scripts. GitHub receives ordinary website and download requests when you use its services.

Distribution

The public distribution repository includes packaged releases, release notes, checksums and update metadata. The application source code is private.
